# Diagnostics Scripts

Development-time diagnostic tools for the S-Stream LBM solver. These scripts were used during solver development and validation to investigate specific issues. They are **not part of the production solver** and are kept for reference/reproducibility.

## Scripts

| Script | Purpose |
|--------|---------|
| `common.py` | Shared utilities for diagnostic runs |
| `cylinder_check.py` | Cylinder validation checks |
| `force_balance.py` | Check force balance on solid boundaries |
| `geometry_audit.py` | Audit voxelized geometry vs. original mesh |
| `resolution_sweep.py` | Resolution convergence study |
| `setup_audit.py` | Audit solver setup parameters (tau, boundaries, etc.) |
| `steady_tunnel_sphere.py` | Steady-state sphere in tunnel analysis |
| `tunnel_drift.py` | Measure numerical drift in empty tunnel (no solid) |
| `tunnel_variants.py` | Compare different tunnel boundary configurations |

## Data

The `data/` subdirectory contains CSV/PNG outputs from diagnostic runs. These are historical artifacts from solver development and are not regenerated by the test suite.

## Usage

These scripts require the `sstream` package to be installed and a CUDA-capable GPU. They are not part of the standard test suite (`pytest tests/`).

Example:
```bash
python scripts/diagnostics/cylinder_sweep.py --help
```
